# Mental Health in Tech Survey – EDA & Streamlit Dashboard

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Mental Health in Tech Survey dataset to understand mental-health experiences, treatment patterns, workplace support, and employer-provided resources in the technology sector.

An interactive Streamlit dashboard is also included to present the major findings and visualizations.

## Objectives
- Explore and clean the Mental Health in Tech Survey dataset
- Analyze employee mental-health and treatment patterns
- Examine workplace factors related to mental health
- Study employer support, benefits, and care options
- Present insights through 15 EDA visualizations
- Build an interactive Streamlit dashboard

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Jupyter Notebook
- VS Code

## Project Files
- `Mental_Health_Tech_Survey_EDA.ipynb` – Complete exploratory data analysis
- `app.py` – Streamlit dashboard
- `survey.csv` – Dataset used for the analysis

## Key Analysis Areas
The project explores factors such as:
- Age and gender distribution
- Mental-health treatment
- Family history
- Work interference
- Remote work
- Employer-provided mental-health benefits
- Awareness of care options
- Workplace support
- Correlation between numerical variables
- Relationships between important survey variables

## Visualizations
The analysis contains 15 visualizations, including bar charts, distribution plots, comparison charts, a correlation heatmap, and a pair plot.

## Conclusion
The analysis highlights relationships between employee mental health, treatment, workplace conditions, awareness of care options, and employer support. These insights can help organizations better understand mental-health experiences in the technology workforce and improve access to appropriate resources.
